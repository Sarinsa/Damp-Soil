1.20.1-6.0.0
    - Updated to use Crust 5
    - Removed unused event listener AnimalBreedListener.java
    - Disabling farmland trampling in the configs now applies to all blocks that fire BlockEvent.FarmlandTrampleEvent
    - Changed some config fields:
        - Config "crops.toml":
            - The effect of field "general.deny_trampling" is no longer limited to only wet farmland
            - Field "general.growth_chance" has been replaced with block state map "general.growth_chances"
            - Field "general.kill_dry_crops" has been replaced with block state set "general.dies_without_water.list"
            - Field "general.bone_meal_chance.list" has been renamed to "general.bone_meal_chances"
